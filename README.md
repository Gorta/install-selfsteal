# selfsteal-installer

Скрипт для разворачивания ноды **VLESS Reality (self-steal)** за **Caddy**, для панели [Remnawave](https://docs.rw/).

Нода отдаёт сертификат Let's Encrypt на сайте-заглушке и не требует отдельного ACME-клиента (acme.sh и т.п.) — Caddy получает и продлевает сертификат сам.

## Что делает скрипт

- ставит Docker, если его ещё нет
- поднимает Caddy (получает сертификат Let's Encrypt на домен ноды)
- разворачивает `remnanode` с данными из `docker-compose.yml`, который вы берёте из панели
- настраивает ufw (SSH + 80/443 открыты, порт ноды для связи с панелью открыт только с её IP)
- включает BBR и базовые сетевые оптимизации
- случайно подбирает сайт-заглушку из внешнего репозитория (или использует встроенную, если скачать не вышло)

### Как это работает

- Xray слушает `443` и обслуживает VLESS Reality
- весь трафик, который не прошёл Reality-аутентификацию (боты, зонды, случайные посетители), Xray форвардит на `127.0.0.1:9443`
- на `127.0.0.1:9443` сидит Caddy и отдаёт сайт-заглушку — для стороннего наблюдателя порт 443 выглядит как обычный HTTPS-сайт

## Требования

- Ubuntu 24, root-доступ
- поднятая панель Remnawave на другом сервере
- уже созданная в Remnawave нода (Nodes → Create Node) — именно оттуда берётся `docker-compose.yml`
- домен, A-запись которого указывает на IP сервера

## Использование

```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/Gorta/install-selfsteal/main/install-selfsteal.sh)
```

Скрипт спросит:
1. домен ноды
2. email для Let's Encrypt
3. IP панели (для правила ufw — панель должна иметь доступ к порту ноды)
4. содержимое `docker-compose.yml` ноды из панели — вставьте и нажмите `Ctrl+D`

В конце выводит диагностику: кто слушает порты 80/443/9443, какой сертификат отдаёт порт с заглушкой, отвечает ли сайт-заглушка по внешнему пути.
